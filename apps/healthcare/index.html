    La conversación

    ¿Qué puede decidir?

    El sistema solo propone si un expediente administrativo está listo para revisión o necesita documentación. No prioriza pacientes, diagnostica, recomienda tratamientos ni ejecuta citas.

    Pregunta al aula

    Si la documentación está incompleta, ¿qué evidencia pedirías antes de seguir?

    03 · Cambiar y evaluar

    El gate que no deja pasar una regresión

    Evaluación real de reglas

    Un cambio hipotético elimina la comprobación de la derivación. La batería ejecuta las mismas reglas sobre cuatro casos sintéticos y compara resultado esperado y observado.

    07 · Del aula al mundo real

    ¿Qué piezas faltan en una organización?

    Modelos y frameworks

    La explicación opcional utiliza un modelo real; el recorrido sigue siendo determinista y no utiliza un framework de agentes. En producción hay que evaluar también respuestas y herramientas.

    AI gateway

    Puede centralizar acceso a modelos, políticas, límites y métricas. Aquí no hay gateway conectado; LiteLLM es una opción abierta.

    Privacidad y supervisión

    Datos mínimos, acceso controlado, trazabilidad y revisión humana. Esta aplicación es una maqueta docente, no un producto sanitario.

    Demostración exclusivamente educativa · No introducir datos de pacientes. No utilizar para decisiones clínicas ni para gestionar solicitudes reales.
